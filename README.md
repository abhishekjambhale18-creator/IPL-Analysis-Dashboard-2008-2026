> An end-to-end IPL data analysis project covering **19 seasons (2008–2026)** with interactive dashboards, team performance metrics, and venue insights.

---

### 📌 Project Overview

This Excel-based project analyzes **1,243 IPL matches** played across 19 seasons.  
It transforms raw match data into clear insights through PivotTables, KPI dashboards, and multi-dimensional analysis.

---

### 📊 Dashboard KPIs

| KPI | Value |
| --- | --- |
| Total Matches | 1,243 |

| No Result | 9 |
| Tied Matches | 16 |

---

### 🔍 Analysis Sections

**1. Team Performance**
- Total runs scored by each team
- Matches won by each franchise
- Average win margin (by runs)
- Total wickets-based victories

**2. Venue & City Analysis**
- Matches played in each city
- Average runs scored per city
- High-scoring and low-scoring venues

**3. Season Trends**
- Year-wise average runs and wickets
- Growth in scoring over seasons
- Match volume by year

**4. Player of the Match Insights**
- MOTM distribution by result type
- Season-wise MOTM count

---

### 📈 Key Findings

- **Royal Challengers Bengaluru** leads in total runs scored
- **Mumbai** is the most frequently used venue city (187 matches)
- **Royal Challengers Bengaluru** has the highest number of match wins (159)
- Scoring rates increased significantly in recent seasons (2023–2026)
- **New Chandigarh** recorded the highest average match runs (398.5)

### 🚀 How to Run

1. Download and open `IPL 2008-2026.xlsx` in Microsoft Excel
2. Start with the **Dashboard** sheet for a high-level overview
3. Navigate through individual analysis sheets for deeper insights
4. Use filters in PivotTables to explore custom views
